PWE MAC MONITOR
A PARADISE PRODUCTION · 天域文创出品

INSTALLING
1. Drag "PWE MAC MONITOR" onto the Applications folder in this window.
2. Open it from Applications. It has no window — look for the wing mark in your menu bar,
   at the top right of the screen.
3. Click the wing to open the dashboard. Right-click it for settings.

SECURITY
This app is signed with a Developer ID certificate and notarised by Apple, so it opens
normally — there is no warning to click through and nothing to allow in System Settings.
If macOS ever does warn you about a copy of this app, that copy did not come from us.

UPDATING
Quit the running app from the menu bar first, then drag the new version across.
Or install it with Homebrew, which handles that for you:
   brew install --cask kenshinice-ai/tap/pwe-mac-monitor
   brew upgrade --cask kenshinice-ai/tap/pwe-mac-monitor

REQUIREMENTS
macOS 14 (Sonoma) or later, on an Apple Silicon Mac (M1 or newer).
Intel Macs are not supported: the power and per-core data comes from Apple Silicon counters
that do not exist on Intel hardware.

Source code, issues and newer versions:
https://github.com/kenshinice-ai/pwemacmonitor
